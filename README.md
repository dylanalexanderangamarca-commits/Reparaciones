# CellMarket Pro

Aplicación PWA para taller de reparación de celulares.

## Módulos incluidos
- Inicio con estadísticas
- Clientes
- Recibir equipo / órdenes
- Reportes básicos
- Ajustes

## Publicar en GitHub Pages
